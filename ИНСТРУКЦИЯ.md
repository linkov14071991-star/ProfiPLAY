# ProfikArena — Инструкция для запуска

Привет, Игорь! Это пошаговая инструкция по запуску первой игры. Прочитай её один раз до конца, потом делай по шагам. Если что-то непонятно — просто спроси меня.

Что мы сейчас соберём: **мини-приложение в Telegram с игрой «Крокодил» по информатике**. Проверка подписки на канал `@profimatika_inf` встроена.

---

## Что уже готово (это сделал я)

В твоей папке `ProfiPLAY` уже лежит весь код:

**Твоя задача:** выполнить 4 больших шага ниже. На всё уйдёт ~30–40 минут.

## ШАГ 1. Создать бота через @BotFather (5 минут)

1. Открой Telegram и найди контакт **@BotFather** (у него синяя галочка).
2. Нажми **START** (или напиши `/start`).
3. Отправь команду: `/newbot`
4. BotFather спросит имя бота — напиши, например: `ProfiPlay`
5. Потом спросит username — он должен заканчиваться на `bot`, например: `profiplay_bot` (если занят — придумай другой, например `profiplay_igor_bot`).
6. BotFather пришлёт сообщение с **токеном** — это длинная строка вроде `7891234567:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

   ⚠️ **Скопируй этот токен и сохрани в блокноте — он нам понадобится.** Никому его не показывай.

7. Не закрывай BotFather — он ещё понадобится в шаге 4.

---

## ШАГ 2. Добавить бота админом в канал (2 минуты)

1. Открой свой канал **@profimatika_inf**.
2. Тапни на название канала сверху → откроется страница канала.
3. Нажми **Управление** (или карандаш) → **Администраторы** → **Добавить администратора**.
4. Найди своего бота по username (например, `@profiplay_bot`).
5. Отключи ему **все права** (боту они не нужны), оставь только сам факт админства.
6. Нажми **Готово**.

Это нужно, чтобы бот мог проверять, подписан ли пользователь на канал.

## ШАГ 3. Задеплоить на Railway (15–20 минут)

Railway — это бесплатный хостинг. Есть тариф с $5 бесплатных кредитов в месяц — этого хватит на старте.

### 3.1. Заведи аккаунт на GitHub (если ещё нет)

1. Иди на **https://github.com** → **Sign up**.
2. Регистрируйся через email или Google.

### 3.2. Загрузи проект на GitHub

Самый простой способ — через приложение **GitHub Desktop**:

1. Скачай https://desktop.github.com/ и установи.
2. Открой GitHub Desktop, войди в свой аккаунт.
3. **File → Add local repository** → выбери папку `C:\Users\Wide\Documents\ProfiPLAY`.
4. GitHub Desktop скажет, что репозитория нет — нажми **create a repository**.
5. Name: `profiplay` (или как хочешь), Description оставь пустым, Local Path — уже указан.
6. Нажми **Create Repository**.
7. Внизу слева впиши в поле **Summary**: `Initial commit`, нажми **Commit to main**.
8. Наверху нажми **Publish repository** → сними галочку "Keep this code private" (или оставь — не важно) → **Publish Repository**.

Готово, код на GitHub.

### 3.3. Задеплой на Railway

1. Иди на **https://railway.com** → **Login** → войди через GitHub.
2. Нажми **New Project** → **Deploy from GitHub repo** → выбери репозиторий `profiplay`.
3. Railway начнёт сборку. Подожди 2–3 минуты.
4. Когда сборка закончится, **не открывай приложение сразу** — сначала нужно добавить переменные окружения.

### 3.4. Добавь переменные окружения

1. В Railway открой свой сервис (клик на карточку проекта).
2. Перейди на вкладку **Variables**.
3. Нажми **New Variable** и добавь по одной:

   | Имя | Значение |
   |---|---|
   | `BOT_TOKEN` | *токен из шага 1* |
   | `CHANNEL_USERNAME` | `@profimatika_inf` |
   | `WEBAPP_URL` | *пока оставь пустым, добавим ниже* |

4. Перейди на вкладку **Settings** → раздел **Networking** → **Generate Domain**.
5. Railway создаст адрес вроде `profiplay-production.up.railway.app`.
6. Скопируй этот адрес и вернись в **Variables** → в `WEBAPP_URL` впиши: `https://profiplay-production.up.railway.app` (со `https://` в начале, без слэша в конце).
7. Railway автоматически перезапустит сервис.

### 3.5. Проверь, что сервер работает

Открой в браузере адрес `https://твой-адрес.up.railway.app` — должна открыться игра. Если открылась — ура!

## ШАГ 4. Привязать мини-приложение к боту (3 минуты)

Возвращаемся к **@BotFather** в Telegram:

1. Отправь `/mybots` → выбери своего бота.
2. Нажми **Bot Settings** → **Menu Button** → **Configure Menu Button**.
3. Отправь URL твоего приложения (тот же, что в `WEBAPP_URL`): `https://твой-адрес.up.railway.app`
4. Отправь текст кнопки: `🎮 Играть`

Теперь у бота внизу чата будет синяя кнопка "🎮 Играть", которая открывает игру.

Опционально: `/setdescription`, `/setabouttext`, `/setuserpic` — чтобы бот выглядел красиво.

---

## ШАГ 5. Тестируем!

1. Открой своего бота в Telegram (найди по username).
2. Нажми `/start` — бот должен ответить и показать кнопку "🎮 Играть в ProfiPlay".
3. Нажми на кнопку — откроется мини-приложение.
4. Если ты подписан на канал — увидишь экран выбора сложности.
5. Если не подписан — увидишь просьбу подписаться. Подпишись → нажми "Я подписался, проверить".
6. Выбери сложность и длительность → **Начать раунд** → играй.

---

## Что делать, если что-то не работает

- **Бот не отвечает на /start** → проверь в Railway на вкладке **Deployments** → **View Logs**, что бот запустился (должно быть `Бот стартует...`).
- **Мини-приложение открывается, но всех блокирует "нужна подписка"** → проверь, что бот админ канала (шаг 2), и что `CHANNEL_USERNAME` в Variables начинается с `@`.
- **Кнопка "Играть" не появляется** → повтори шаг 4.
- **Мини-приложение вообще не открывается** → зайди на URL из браузера. Если не открывается там — проверь логи в Railway.

Скинь мне скриншот ошибки — я подскажу что делать.

## ⚠️ ВАЖНО после Этапа 9: настройка Railway Volume для базы данных

Мы теперь храним игроков и их рейтинги в SQLite. Без **Volume** база будет обнуляться при каждом перезапуске сервиса на Railway. Настрой один раз — потом забудешь.

### Шаг 1. Создать Volume в Railway

1. Открой свой проект на **railway.com** → тапни на карточку сервиса `web`.
2. Перейди на вкладку **Settings** → прокрути до раздела **Volumes** (или **Storage**).
3. Нажми **New Volume** / **+ Add Volume**.
4. **Name:** `data`
5. **Mount Path:** `/app/data`
6. Нажми **Add** / **Create Volume**.

### Шаг 2. Указать backend'у путь к БД

1. Вкладка **Variables** → **New Variable**:
   - Имя: `DB_PATH`
   - Значение: `/app/data/profikarena.db`
2. Нажми **Add** → потом фиолетовую кнопку **Deploy** сверху, если она появилась.

Railway сам пересоберёт и подключит том. Проверь во вкладке **Deployments** → **View Logs** — не должно быть ошибок про создание БД.

### Что будет, если пропустить?

Приложение всё равно запустится: база создастся в текущей папке контейнера и будет работать. НО при первом же перезапуске (обновление кода, автоматический рестарт Railway) — **все игроки, их рейтинги и история будут потеряны**. Поэтому настраиваем Volume до того, как начнёшь тесты с реальными пользователями.
