# Переезд на @ProfikArena_bot — пошагово

Код менять не нужно. Весь прогресс (рейтинг, XP, ачивки, стрики, история дуэлей)
привязан к твоему Telegram ID, а не к боту — база та же, всё сохранится.

---

## Часть 1. Токен нового бота (@BotFather)

1. Открой **@BotFather** в Telegram.
2. Получи токен ProfikArena_bot:
   - **Если бот уже создан:** `/mybots` → выбери **ProfikArena_bot** → **API Token** → скопируй.
   - **Если ещё нет:** `/newbot` → задай имя (напр. «Профик Arena») → username `ProfikArena_bot` → BotFather пришлёт токен.
3. Токен выглядит примерно так: `1234567890:AAE-xxxxxxxxxxxxxxxxxxxx`. Скопируй его целиком.

## Часть 2. Сделай бота админом канала

4. Открой канал **@profimatika_inf** → **Управление каналом** → **Администраторы** → **Добавить администратора**.
5. Найди **@ProfikArena_bot** и добавь. Особые права не нужны — важно, чтобы бот был админом.

> ⚠️ Без этого шага проверка подписки не работает и приложение блокирует всех сообщением «нужна подписка».

## Часть 3. Railway (переменные)

6. Открой проект на **railway.app** → свой сервис → вкладка **Variables**.
7. Поменяй **`BOT_TOKEN`** → вставь новый токен из шага 2.
8. Поменяй **`BOT_USERNAME`** → `ProfikArena_bot` (без `@`).
9. **Не трогай:** `WEBAPP_URL`, `CHANNEL_USERNAME`, `DB_PATH` (и `ADMIN_IDS`, если настроишь).
10. Сохрани. Railway передеплоит сам. Если нет — вкладка **Deployments** → **Redeploy**.

## Часть 4. Проверка

11. Открой **@ProfikArena_bot** → `/start` → нажми **«🎮 Играть»**.
12. Проверь: мини-приложение грузится, экран подписки пропускает, профиль и рейтинг на месте.
13. Создай дуэль — ссылка должна быть вида `t.me/ProfikArena_bot?start=duel_...`.

## Часть 5. Старый бот (по желанию)

14. У старого бота в @BotFather убери кнопку-меню / веб-апп или поставь описание «Переехали в @ProfikArena_bot», чтобы туда не заходили. (Старый бот всё равно перестанет отвечать — один токен опрашивает только один процесс.)

---

### Если что-то пошло не так

- **Всех блокирует «нужна подписка»** → бот не админ канала (Часть 2), либо `CHANNEL_USERNAME` не начинается с `@`.
- **Мини-апп не открывается / старая версия** → нажми Redeploy; бот на старте сам обновляет кнопку-меню со свежей версией.
- **Дуэль-ссылка ведёт на старого бота** → проверь, что `BOT_USERNAME` = `ProfikArena_bot` и сервис передеплоился.
