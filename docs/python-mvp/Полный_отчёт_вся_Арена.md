## 1. Что это за платформа

**Профик Арена** — образовательно-игровая платформа в виде Telegram Mini App для учеников Профиматики (подготовка к ОГЭ/ЕГЭ по информатике). Цель — вовлечь школьников заниматься каждый день через геймификацию и не бросить.

Платформа объединяет три вида активности:
- **Соревновательные викторины** (Спринт, Марафон, Блиц-дуэль) — быстрые вопросы по информатике, математике и программированию с рейтингом и лигами.
- **Командные игры для компании** (Крокодил, Alias, 5 секунд, Шпион, Кто я?) — офлайн-развлечения на одном устройстве.
- **Python-курс** — структурированный адаптивный тренажёр подготовки к ОГЭ/ЕГЭ.

Обязательное условие входа — подписка на Telegram-канал `@profimatika_inf` (драйвер роста аудитории канала).

## 3. Игровые режимы — СОЛО

### 🏃 Спринт
Быстрая викторина на время. Вопрос + 4 варианта, один правильный. За правильный ответ — рейтинг и XP. Три уровня сложности (простая/средняя/сложная) с множителями. Дисциплины: информатика, математика, программирование (единый пул). Есть личный рекорд.

**Начисление:** rating = число правильных × 1 (база спринта) × множитель сложности. XP = rating × 2.

### 🏆 Марафон
Пройти как можно дальше на ограниченном числе жизней. Выбор жизней: **1 / 3 / 5** — чем меньше жизней, тем выше множитель за риск (1 жизнь = ×3, 3 жизни = ×2, 5 жизней = ×1). Ошибка отнимает жизнь. Есть личный рекорд «максимальная серия».

**Начисление:** rating = число правильных × 2 (база марафона) × множитель сложности × множитель жизней. XP = rating × 1.5.

### 🐍 Python-курс
Отдельный большой раздел (см. п.6 и детальный отчёт). Начисляет XP всегда и рейтинг — за первое прохождение урока.

**Общий для викторин механизм:** варианты ответов перемешиваются на сервере (антипаттерн «правильный всегда первый» устранён). Дневной кап рейтинга за тренировки — **100** (защита от гринда).

## 4. Игровые режимы — ТУСОВКА (для компании)

Командные игры на одном устройстве. **Баллы НЕ начисляются** в рейтинг (осознанное решение против накрутки — «во избежание накрутки баллов к личному рейтингу»). Прогресс квестов/ачивок при этом идёт.

### 🎭 Крокодил
Показывай слово жестами, команда угадывает. База слов по информатике, 3 уровня сложности, таймер, счётчик угаданных/пропущенных.

### 🃏 Alias
Объясняй слово словами (не однокоренными), команда угадывает. К словам приложены запретные слова. 3 уровня сложности.

### ⏱️ 5 секунд
Назови 3 варианта по категории за 5 секунд. 93 категории по информатике (3 уровня сложности).

### 🕵️ Шпион
Всем игрокам показывается локация/тема, кроме шпиона. Задача — вычислить шпиона по ответам. Раздача ролей на одном устройстве.

### 🤔 Кто я?
Игрок не видит своё слово (на лбу), задаёт вопросы, угадывает по ответам команды.

**Контент Тусовки:** 90 слов (Крокодил/Alias) + 93 категории (5 секунд), по 3 уровня сложности.

## 5. Блиц-дуэль (ProfikCup)

Дуэль 1 на 1 в реальном времени. Инициатор создаёт дуэль → получает deep-link `t.me/bot?start=duel_XXX` → отправляет сопернику. Оба отвечают на одинаковый набор вопросов, сравниваются результаты.

**Рейтинг по ELO** (K-фактор 32), **асимметричный**: победитель получает полный выигрыш, проигравший теряет вдвое меньше. Ничья — симметрично. Пример: победа +30, поражение −15.

**XP:** победа +50, ничья +30, поражение +20.

Есть история дуэлей (кто, когда, результат) и виральная карточка результата (Canvas) для шаринга.

## 7. Мета-игра: XP и уровни

**XP** — опыт для уровня аккаунта. Начисляется за всё: викторины, дуэли, Python, вход в новый день, квесты, милстоуны серии.

**Формула уровня:** для достижения уровня N нужно всего `100 × N × (N−1) / 2` XP (квадратичная кривая — каждый уровень дороже предыдущего). XP-полоса в шапке показывает прогресс до следующего уровня.

**Титулы игрока** (под ником) — по преобладающей активности: Марафонец, Дуэлянт, Спринтер и т.п.

## 8. Мета-игра: Рейтинг и Лиги

**Рейтинг** (старт 1000) — соревновательный показатель для лиг и лидерборда. Растёт за викторины, дуэли (ELO), Python (первое прохождение).

**5 лиг** по порогам рейтинга, каждая (кроме Легенды) делится на 3 подуровня (тиера I/II/III):

| Лига | Порог рейтинга | Иконка |
|---|---|---|
| 👑 Легенда | 1900+ | без тиеров |
| ⭐ Стар | 1600–1899 | I/II/III |
| 🚀 Синьор | 1300–1599 | I/II/III |
| 💻 Мидл | 1000–1299 | I/II/III |
| 🎓 Юниор | 0–999 | I/II/III |

**Лидерборд:** общий (топ по рейтингу) + недельный + «соседи» (игроки рядом с тобой по рейтингу). Бейдж лиги показывается у ника.

## 12. Формулы начисления

**Множители сложности** (все викторины): простая ×1.0, средняя ×1.5, сложная ×2.0.

**Множители жизней (Марафон):** 1 жизнь ×3.0, 3 жизни ×2.0, 5 жизней ×1.0.

**База рейтинга за правильный ответ:** спринт 1, марафон 2, тусовка 0.

**XP за очко рейтинга:** спринт ×2.0, марафон ×1.5, тусовка ×3.0 (но рейтинг тусовки = 0).

**ELO дуэлей:** K=32, асимметричный (проигравший теряет вдвое меньше).

**XP дуэлей:** победа 50, ничья 30, поражение 20.

**Дневной кап рейтинга за тренировки:** 100.

**Python-рейтинг:** 2–15 за первое прохождение урока (от сложности урока × точность), только один раз на урок.

## 14. Бэкенд: API и база данных

**FastAPI** на Railway. SQLite с постоянным хранением (Railway Volume).

**Таблицы БД:**
- `users` — telegram_id, имя, rating (1000), xp (0), streak, даты, счётчики.
- `rating_log` — история изменений рейтинга (источник, дельта, баланс).
- `xp_log` — история XP.
- `duels` — дуэли (участники, вопросы, результаты, статус).
- `python_completed` — зачтённые уроки Python (для рейтинга за первое прохождение).
- квесты и достижения пользователей.

**API-эндпоинты (26):**
- `check_subscription` — проверка подписки на канал.
- `words`, `alias`, `questions`, `categories`, `spy`, `marathon` — контент игр.
- `config` — множители и настройки.
- `profile` — профиль игрока.
- `rating/training` — начисление за спринт/марафон/тусовку.
- `achievements`, `quests/daily`, `quests/claim` — квесты и ачивки.
- `leaderboard`, `leaderboard/neighbors`, `leaderboard/weekly`, `leaderboard/me` — лидерборды.
- `duel/create`, `duel/{id}/join`, `duel/{id}/submit`, `duel/{id}`, `duels/history` — дуэли.
- `python/session_end`, `python/telemetry_batch` — Python.

## 15. Аутентификация и безопасность

- **Проверка Telegram initData** через HMAC-SHA256 с токеном бота — сервер убеждается, что запрос действительно от Telegram.
- **Рейтинг считается на сервере** — клиент присылает сырые данные (число правильных), сервер применяет множители и капы. Накрутка через подделку баллов невозможна.
- **Python-рейтинг:** сервер хранит зачтённые уроки — повторная накрутка невозможна.
- **Дневной кап** рейтинга за тренировки (100) — защита от гринда.
- **Тусовка = 0 рейтинга** — нельзя накрутить командными играми.
