## Что решено (ключевые ответы эксперту)

**Первая волна фидбека:**

1. **Execution Engine** введён как отдельный слой (TDD §4). Renderer не знает Python.
2. **Learning Beats** — уровни строятся по эмоциям, не по сложности (GDD §4, LDB §2).
3. **Difficulty Matrix** — 6 осей для балансировки (LDB §1).
4. **Telemetry** — детальная схема с ключевой метрикой `code_run_count_per_success` (TDD §11, LDB §9).
5. **Replay** — контроллер 0.5×/1×/2×/step (TDD §12).
6. **Sandbox** — после каждого мира (GDD §7, LDB §6).
7. **Педагогическая таблица** — почему каждая визуализация нужна (GDD §5).
8. **Демо-мир (Пролог)** — 4 сцены до Дюн (GDD §6, LDB §4).
9. **Формат Feature Specification** — каждый уровень как feature spec (LDB §3).

**Вторая волна фидбека:**

10. **Project Principles** — новый документ 00 с миссией, Pillars, framework (`00_ProjectPrinciples.md`).
11. **Эмоция как причина обучения** — Pillar 2, обновление pacing curve (LDB §2).
12. **Пролог ≤ 40 секунд**, первое «Работает!» ≤ 30с (LDB §4).
13. **Object Model через фабрику** — регистрация типов, не хардкод (TDD §6).
14. **Replay только после победы** — жёсткое правило (TDD §12).
15. **Расширенная телеметрия** — 25 event types + концептуальные эвристики (TDD §11).
16. **Обновлённые оценки тайминга** — реалистичнее (см. ниже).
17. **4 продуктовых вопроса** — в 00, ожидают ответа Игоря.

## Тайминг производства (реалистичная оценка после второй волны фидбека)

### Срез (Пролог + Дюны 10 уровней + Sandbox)

**Оценка: 250-350 часов.** Эксперт согласен, что это реалистично.

Разбивка — см. предыдущую версию README (256 часов), плюс запас на факторы Мёрфи.

Реалистично для одного full-time разработчика — **7-9 недель**, для part-time — **3-4 месяца**.

### Полная игра (15 миров + финал)

**Обновлённая оценка: 700-1000 часов** сверх среза (эксперт прав, 500 было оптимизмом).

Причины пересчёта:
- Первый мир — самый дорогой (движок, паттерны, ассеты). Второй-пятый — дешевле.
- Но потом появляется: балансировка контента, переработки по фидбеку, музыка, дополнительные анимации, исправления, интеграция.
- Плюс сам финал `>>> _` с `print("Спасибо.")` — отдельная церемония на ~30-40 часов.

Для full-time — **7-12 месяцев** до законченной версии.

Это нормально. Хорошие игровые продукты столько и делаются.

## Философия проекта

Из GDD §1:

> **Игра, в которой ребёнок учится Python, но чувствует, что проходит приключение.**

Слоган:

> **«Твой код оживает на экране.»**

Всё в этих документах существует ради усиления этого чувства. Если что-то из спеки этому противоречит — вырезаем.
