# Python-курс «Профик Арены» — образовательный трек ОГЭ/ЕГЭ

**Что это:** Duolingo-style курс Python для подготовки к ОГЭ и ЕГЭ по информатике.
Не игра-аркада, а структурированный курс: уроки от простого к сложному, тесты, ежедневные повторения, streak.

> Прошлая концепция «Живой Python» (анимация Профика) удалена по решению продукта.
> Аудитория — школьники 9-11 классов, готовящиеся к экзамену.

---

## Как это работает для ученика

1. **Онбординг.** Профик здоровается, спрашивает цель (ОГЭ / ЕГЭ / просто выучить) и опыт. Если ученик не новичок — короткий placement-тест из 6 вопросов возрастающей сложности. По результату рекомендуется, с какой темы начать.
2. **Дерево тем.** 15 юнитов от «Первые шаги» (print) до «Задачи ЕГЭ». Тёмно-зелёные — ОГЭ, оранжевые/фиолетовые — ЕГЭ. Уроки открываются по порядку, пройденные отмечаются галочкой и короной за точность.
3. **Урок.** 4-8 заданий трёх типов (см. ниже). 5 сердечек. Ошибся — теряешь сердце, задание возвращается в конец. Кончились сердца — урок начинается заново.
4. **Ежедневное повторение.** Карточка на главной: 8 случайных вопросов из уже пройденного. Держит streak.
5. **Результат.** XP, точность, серия. XP уходит на бэкенд и суммируется с общим профилем Арены.

---

## Три типа заданий

| Тип | Что делает ученик | Пример |
|---|---|---|
| **Выбор варианта** (mcq) | Тапает 1 из 4 ответов | «Какая команда выводит текст? → print» |
| **Что выведет код** (output) | Читает код, печатает результат | `print(17 % 5)` → `2` |
| **Собери код** (assemble) | Ставит перемешанные строки в порядок | `x = 7` / `print(x)` |

Все ответы типа output **проверены на настоящем Python** (63 кейса, 100% совпадение).

## Программа курса

### ОГЭ (8 юнитов, от простого)
1. Первые шаги — print, комментарии
2. Переменные — типы, присваивание
3. Ввод данных — input, int()
4. Арифметика — //, %, **
5. Условия — if / elif / else
6. Цикл while
7. Цикл for и range
8. Строки — len, индексы, перебор

### ЕГЭ (7 юнитов, надстройка)
9. Списки — индексы, методы, срезы
10. Вложенные циклы
11. Функции — def, return
12. Строки продвинуто — срезы, методы
13. Словари и множества
14. Библиотеки — math, random
15. Задачи ЕГЭ — типовые разборы

**Итого:** 15 юнитов, 20 уроков, 91 вопрос. Это стартовая база — легко расширять.

## Файлы

```
frontend/python/
  index.html              # 4 экрана: онбординг, дерево, урок, результат
  style.css               # Duolingo-подобный стиль
  src/
    main.js               # роутер + состояние + прогресс
    onboarding.js         # анкета + placement-тест
    tree.js               # дерево тем
    lesson.js             # плеер урока (3 типа заданий, сердечки)
    daily.js              # ежедневное повторение
    curriculum/
      index.js            # сборка программы
      oge.js              # 8 юнитов ОГЭ (проверено Python)
      ege.js              # 7 юнитов ЕГЭ (проверено Python)
    ui/highlight.js       # подсветка Python-кода
    audio/sound_engine.js # звуки (Web Audio)
    state/cloud_storage.js# прогресс в Telegram CloudStorage
    telemetry/client.js   # телеметрия
```

Прогресс хранится в CloudStorage (`pycourse.state`): пройденные уроки, короны, XP, streak, дата последней активности, дата пройденной ежедневки.
