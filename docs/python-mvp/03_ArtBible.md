## 1. Общее настроение

Одна фраза:

> **Тёплое ретро-приключение, не аркада.**

Три референса стиля:
- **Monument Valley** — плоские формы, чистые цвета, тишина.
- **Alto's Odyssey** — минимализм, силуэты, драматичный свет.
- **Untitled Goose Game** — характер персонажа, отсутствие лишних деталей.

Не референсы:
- Neon, glitch, cyberpunk.
- Реалистичный 3D.
- Мультяшный «диснеевский» стиль.

## 3. Профик — визуальная библия

### 3.1. Базовый спрайт

Уже существует: `frontend/profik.svg` (чёрный кот в худи, `</>` на груди, пиксельные глаза).

Все состояния — производные от этого спрайта через transform + swap глаз.

### 3.2. Состояния (для среза)

| State | Триггер | Как | Duration |
|---|---|---|---|
| `idle` | по умолчанию | лёгкое дыхание (scaleY 1.0 → 1.03), моргание раз в 4 сек | loop |
| `thinking` | долгий idle игрока (>5с) | лапа у подбородка, вопросительный знак | loop |
| `hop` | ProfikHop event | translateX + Y-парабола + `sfx.tile_hop` | 350ms |
| `walk` | ProfikStep event | покачивание тела, ноги переставляются | 200ms/шаг |
| `run` | после разблокировки способности «Бег» | как walk, но 2× быстрее + пыль | 100ms/шаг |
| `cheer` | level_complete | подпрыгивает, лапы вверх | 800ms one-shot |
| `sad` | RuntimeError | опустил уши, отвернулся | 500ms → возврат в idle |
| `say` | ProfikSay event | облако с текстом сверху, лёгкая улыбка | зависит от длины |
| `sleep` | не играли 24ч+ | Zzz, лежит | loop (только на карте) |

### 3.3. Правила анимации

- Все переходы через `easeOutBack` для «упругости».
- Никогда не остаётся неподвижным больше 4 сек — обязательно моргание.
- В `hop` и `cheer` — легкий stretch (scaleY 0.9 в момент отталкивания, 1.1 в пике).

### 3.4. Формат ассетов

- Один мастер-SVG (`profik_master.svg`) с всеми компонентами (тело, глаза-варианты, лапы-варианты).
- Рантайм композит через `<g>` группы + display none/block.
- Никаких PNG-спрайтшитов для среза (SVG хватит).

## 4. UI-компоненты

### 4.1. Коробка переменной (VariableBox)

```
┌───────┐
│   x   │  ← имя сверху
├───────┤
│   5   │  ← значение внутри, шрифт JetBrains Mono
└───────┘
```

- Размер: 64×80px.
- Цвет: `--py-var-box`, скруглённые углы 8px.
- Подсветка при `VariableAssigned` — свечение `--py-highlight` пульсирует 400ms.
- При смене значения — старая цифра уходит вверх с fade, новая приходит снизу.

### 4.2. Поезд списка (ListTrain)

```
┌───┐ ┌───┐ ┌───┐
│10 │═│20 │═│30 │
└───┘ └───┘ └───┘
```

- Вагон: 56×56px, цвет `--py-list-train`.
- Стыковки — короткие линии между вагонами.
- `append` — новый вагон едет справа с bounce.
- `pop` — вагон отскакивает вверх и исчезает.

### 4.3. Дорожка range (RangePath)

Плитки в ряд, с отступом 4px.

- Обычная плитка: `--py-range-tile`, 48×48px.
- Активная (Профик на ней): `--world-dunes-tile-active` + свечение.
- Пройденные — с чуть меньшей насыщенностью.
- Плитка отсутствует между шагами (`range(0,10,2)` = плитки 0,2,4,6,8, но визуальные щели показывают что там ничего нет).

### 4.4. Редактор кода (Editor)

**Block-mode:**
- Токены-блоки: скруглённые (8px), фон по типу токена (см. Python palette).
- Drag & drop с haptic light при начале и success при drop.
- «Мусорка» справа — тащим туда чтобы удалить.

**Text-mode:**
- Моноширинный (JetBrains Mono), 16px.
- Подсветка синтаксиса — только 4 категории (keyword, string, number, comment).
- Курсор `--py-var-box`, blink 500ms.
- Автоотступ после `:`.

### 4.5. Кнопка ▶ показать

Она — главная. Дизайн должен выделять.

```
┌──────────────────────┐
│  ▶  показать         │
└──────────────────────┘
```

- Ширина: 80% экрана, снизу над клавиатурой.
- Фон: gradient `--arena-primary` → чуть темнее.
- Тень мягкая (0 4px 12px `--arena-primary` @ 0.3 opacity).
- Тап: scale 0.95 → 1.0 с bounce, haptic medium.
- В момент воспроизведения меняется на `⏸ пауза`.

### 4.6. Реплика Профика (ProfikDialog)

Облако сверху canvas, треугольник вниз-влево к голове Профика.

- Фон: `--arena-surface` с 4px border `--arena-primary`.
- Появление: fade + slide down 200ms.
- Исчезновение: fade 300ms или тап.
- Автозакрытие через `2500ms + 60ms × длина текста`.
- Одна реплика на экране (следующая заменяет).

### 4.7. Консоль (для print)

Небольшая полоска над canvas в момент `PrintCalled`:

```
> Привет
```

- Моноширинный, `--py-code-bg` фон.
- Появление: text-typing эффект (по одному символу, 30ms/символ).
- Держится до конца программы, затем свёртывается.

### 4.8. Кнопка Sandbox

На экране мира, справа снизу.

```
┌──────────┐
│    🧪    │
│песочница │
└──────────┘
```

Отдельный от кнопки «дальше» — не путать.

### 4.9. Replay controls

Появляется под canvas после `level_complete`:

```
◀◀   ◀|   ▶ 0.5×   ▶ 1×   ▶ 2×   |▶   ▶▶
```

- Кнопки: 40×40px, круглые.
- Активная скорость подсвечена `--arena-primary`.
- Скрывается кнопкой «дальше».

## 5. Карта мира

Свиток, разворачивающийся вертикально.

### 5.1. Точки миров

15 точек на пути:
1. **Открытая пройденная** — цветная, оживлённая (движение, звук окружения).
2. **Открытая текущая** — пульсирует `--arena-primary`.
3. **Закрытая доступная** — серая с иконкой замка.
4. **Закрытая недоступная** — силуэт без деталей.

### 5.2. Оживление после прохождения

Момент перехода:

1. Игрок возвращается на карту после `world_complete`.
2. Точка мира замерла в старом (закрытом) состоянии 800ms.
3. Вспышка `--arena-primary` (200ms).
4. Плавный переход в оживлённое состояние (2000ms):
   - Дюны — начинают шевелиться (parallax), появляются след Профика, песчинки, слышен ветер.
   - Появляется маленький Профик, машет лапой.
5. Раскрывается путь к следующей точке (линия рисуется 800ms).
6. Следующая точка меняет силуэт на серый (стала «доступной»).

Общая длительность события: ~4 сек. Пропуск тапом невозможен — это payoff-момент.

### 5.3. Свиток

Стилизация под старую карту:
- Текстура пергамента (SVG noise + сепия).
- Точки миров — иконки в стиле рукописных значков.
- Между точками — извилистая линия (bezier), рисуется по мере разблокировки.

## 6. Ceremonial moments (важные события)

Три особых момента с усиленным арт-исполнением:

### 6.1. Раскрытие Осколка

Триггер: прошёл финальный уровень мира.

Последовательность (3.5 сек):
1. Экран затемняется (400ms).
2. Из центра поднимается 3D-карточка (600ms, `easeOutBack`).
3. Карточка вращается в 3D (перед → тыл → перед), показывая иллюстрацию (1200ms).
4. Появляется надпись: **«Осколок раскрыт»** + название (400ms).
5. Одна строка лора внизу карточки (600ms fade in).
6. Кнопка «дальше» (появляется через 300ms после лора).

Звук: `sfx.shard_reveal` (1500ms fanfare).
Хаптик: success → 400ms → success.

### 6.2. Оживление мира (см. 5.2)

### 6.3. Разблокировка способности Профика

После оживления мира — Профик приходит на карту и говорит:

- «Умею теперь бегать. Показать?»
- Игрок тапает «да» → короткая пробежка через оживлённый мир (2 сек).
- Появляется иконка способности в углу.

Единожды. При следующих заходах — без ceremony.

## 7. Motion principles

Пять правил для всех аниматоров:

1. **Ничего не появляется резко.** Минимум `fade 150ms` или `scale from 0.9`.
2. **Всё что двигается — с ease-out.** Никогда `linear` кроме loop-окружения.
3. **Bounce используем экономно.** Только для «выигрышных» событий (hop, cheer, correct).
4. **Тишина ценнее движения.** Если можно не анимировать (текст на кнопке, статичные иконки) — не анимируем.
5. **Синхронизация звука и движения.** Пиковая точка звука должна совпасть с пиковой точкой анимации в пределах ±30ms.

## 8. Sound catalog (детально)

Дублирует и расширяет `02_TDD.md` §8.2.

### 8.1. Спецификация каждого файла

| Ключ | Тип | Длит. | Частота | Источник | Обработка |
|---|---|---|---|---|---|
| `sfx.box_open` | one-shot | 90ms | 22kHz | freesound.org #245 | -6dB, fade out 20ms |
| `sfx.box_fill` | one-shot | 120ms | 22kHz | freesound.org #382 | pitch +2 semitones |
| `sfx.tile_step` | one-shot | 80ms | 22kHz | freesound.org #611 | -3dB |
| `sfx.tile_hop` | one-shot | 150ms | 22kHz | freesound.org #611 | pitch +5, brighter |
| `sfx.correct` | one-shot | 250ms | 44kHz | freesound.org #720 | нормализация |
| `sfx.error` | one-shot | 300ms | 22kHz | freesound.org #920 | low-pass 2kHz |
| `sfx.shard_reveal` | one-shot | 1500ms | 44kHz | freesound.org #1104 | reverb добавить |
| `sfx.print_bubble` | one-shot | 180ms | 22kHz | freesound.org #340 | — |
| `sfx.train_add` | one-shot | 220ms | 22kHz | freesound.org #444 | — |
| `env.dunes` | loop 20s | 22kHz | freesound.org #55 | seamless loop, -12dB |

**Все ID freesound — placeholder.** Sound-дизайнер подбирает конкретные звуки, соответствующие настроению.

### 8.2. Единый sonic identity

Три правила:
- Все `sfx` — короткие, деревянно-мягкие (тук, шелест, дзынь). Не металл, не электроника.
- Все `error` — приглушённые, не резкие. Ошибка не должна пугать.
- `env` — реалистичное окружение (ветер, песок, вода в других мирах).

### 8.3. Отсутствие музыки в срезе

**Осознанное решение.** Музыка требует больше времени/бюджета, а звук окружения + sfx уже создают атмосферу.

Место под музыку зарезервировано: `audio/music/dunes_theme.ogg` может быть добавлено в v1.1 без изменения архитектуры.

## 11. Формат deliverables от дизайнера

Что арт-команда сдаёт разработчику:

1. **Профик** — один мастер-SVG со всеми состояниями как `<g>` группы. Файл `profik_master.svg`.

3. **Дюны** — три файла:
   - `dunes_bg_static.svg` — фон без движения.
   - `dunes_bg_alive.svg` — активный фон с parallax-слоями.
   - `dunes_tile_variants.svg` — 4 варианта плитки (обычная, активная, пройденная, отсутствующая).
4. **Осколок «Песочные Часы»** — 3D-карточка, PNG или Lottie.
5. **Иконки** — 3 SVG (см. §10).
6. **Звуки** — 10 файлов, названия по §8.1, формат OGG.

Все ассеты — в `frontend/python/assets/`, sub-папки по типу.

## 12. Accessibility

Минимальные требования:

- Контраст текста к фону ≥ 4.5:1 (WCAG AA).
- Кнопка ▶ показать читается через VoiceOver / TalkBack.
- Настройка «reduced motion» — все анимации × 0.5 длительности + отключаются bounce и camera shake.
- Опция «звук выкл» глобально.

Не в срезе (но в бэклоге): dyslexia-friendly font, colorblind palette.

## 13. Что арт-команда НЕ делает в срезе

- Кастомные шрифты (используем Onest + JetBrains Mono).
- 3D-модели (всё 2D SVG или canvas 2D).
- Cutscenes (только реплики Профика + оживление карты).
- Персонажи кроме Профика.
- Другие миры кроме Дюн + иконки-заглушки на карте.
- Настоящая музыка (см. §8.3).
