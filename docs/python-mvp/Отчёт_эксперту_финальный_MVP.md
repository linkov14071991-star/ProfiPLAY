## 2. Что реализовано по твоим рекомендациям

### Контент (ты: «самый важный совет»)
- **552 вопроса, 78 уроков, 28 тем** (8 ОГЭ + 20 ЕГЭ).
- Все **354 задания «что выведет код» проверены на настоящем Python** — нулевой риск неверных ответов.
- Баланс типов приведён к рекомендованному: output 64%, mcq 20%, «найди ошибку» 8%, «собери код» 8%.
- Теория: 127 блоков + 35 практических советов «💡 частая ошибка».

### Структура «по задачам ЕГЭ» (ты: «самый важный следующий шаг»)
Гибрид Python → Библиотеки → Задачи. Библиотека — инструмент, задача экзамена — главная сущность. Задачи-боссы:

| Тема | Вопросов | Что внутри |
|---|---|---|
| Задача №24 (строки/re) | 32 | классы, квантификаторы, жадность/лень, finditer, шаблоны |
| Задача №25 (маски/делители) | 32 | перебор до √n, fnmatch, простые числа, шаблоны |
| Задача №27 (данные/dist) | 28 | расстояния, медоид, кластеры, ближайшая пара |
| Задача №8 (комбинаторика) | 7 | product, перестановки, сочетания |

Плюс библиотеки как отдельные темы: math, itertools, functools/рекурсия, re, fnmatch, ipaddress, файлы/f-строки, geometry, turtle — по главе автора, привязка к номерам задач.

### Персонализация (ты: «сильнее любых анимаций»)
- **Память Профика:** отслеживает точность по каждой теме, находит слабую (<75%), предлагает целевое повторение. Реплики адаптируются: слабая тема / возврат после отсутствия / похвала / streak.
- **«План на сегодня»:** авто-план из статистики — повторить слабое, исправить 3 ошибки, решить задачу ЕГЭ, посмотреть видео. Объединяет контент + персонализацию + мотивацию.
- **Индекс готовности (0-100):** точность 40% + стабильность 25% + скорость 20% + сложные задачи 15%. Нерешённые задачи-боссы честно держат готовность ниже 85.

### Обучающие инструменты (ты: «больше пользы, чем ещё 50 вопросов»)
- **Пошаговая трассировка:** мини-интерпретатор Python на JS проигрывает код по шагам после ошибки. Показывается ТОЛЬКО если вывод совпал с проверенным ответом (гарантия корректности). Покрытие ~72%.
- **Тип «Найди ошибку» (🐞):** код с багом, выбрать что не так.
- **Мини-проекты (без интерпретатора):** 6 проектов пошаговой сборки настоящей программы (калькулятор, шифр Цезаря, таблица умножения, статистика, угадай число, пароль). В конце — витрина с готовым кодом + пример запуска.

### Видео (уникальный актив)
- Авторский марафон **Py.Go: 25 дней кода** полностью встроен. Тап открывает ролик во внешнем YouTube (обошли авторизацию во встроенном плеере Telegram). Видео привязаны к темам + отдельный экран «Видео-марафон».

### Механики удержания
Сердечки, streak, ежедневное повторение, тест недели (ротация, сброс в понедельник), короны за точность, XP (единый с общим профилем Арены).

## 4. Технические факты
- **Frontend:** ванильный JS (ES-модули), ~5750 строк, 30 файлов, без фреймворков.
- **Хранение:** двойное — Telegram CloudStorage + localStorage, выбор свежей версии по метке времени (защита от лимита 4096 байт и потери профиля).
- **Backend:** FastAPI на Railway. Эндпоинты начисления XP и приёма телеметрии.
- **Телеметрия:** собирает старт/финиш урока, правильность, первую попытку, время ответа, использование трассировки/видео/теории, вход в проекты. Готова к анализу.
- **Контроль качества:** весь выводимый контент прогоняется через реальный Python-интерпретатор в CI-скриптах.

## 5. Полный путь ученика
1. Онбординг (один раз): цель ОГЭ/ЕГЭ, опыт, placement-тест из 6 вопросов → рекомендация стартовой темы.
2. Дерево тем: 28 тем от print до задач ЕГЭ, короны за точность.
3. Сверху дерева: план на сегодня, индекс готовности, баннер Профика, тест недели, ежедневка, проекты, видео-марафон.
4. Теория (по желанию) с примерами, видео и советами.
5. Урок: 6-12 заданий 4 типов, 5 сердечек, разбор ошибки с трассировкой.
6. Прогресс, XP, streak — сохраняются, XP вливается в общий профиль Арены.

## 7. Конкретные вопросы по направлениям

1. **Метрики первого теста.** Какие 3-5 показателей телеметрии считать главными сигналами на старте? (завершение первого урока, D1/D7 retention, точность по темам, доля дошедших до задач-боссов, использование трассировки?) Хочу настроить дашборд под них.

2. **Кабинет учителя.** Игорь — преподаватель с каналом. Стоит ли делать учителю обзор прогресса учеников (кто где застрял, средняя готовность группы)? Это требует аккаунтов/агрегации на бэкенде. Или на этом этапе избыточно?

3. **Задача №8 и остальные номера.** Мы углубили 24/25/27 (по 30 вопросов). Задача 8 пока 7 вопросов. Довести ли её и другие частые номера (11, 13, 16) до той же глубины сразу, или сначала посмотреть, до каких вообще доходят ученики?

4. **Индекс готовности как ядро.** Сейчас это карточка. Не сделать ли его центральным экраном/целью всего продукта («доведи готовность до 80 к экзамену»), вокруг которого строится вся мотивация?

5. **Разбор полной задачи ЕГЭ.** У нас есть шаблоны решений в теории и тренировочные вопросы по частям. Не хватает ли режима «собери решение целиком под конкретную задачу с проверкой каждого шага» — как расширение мини-проектов, но на задачах 24-27?

6. **Монетизация / канал.** Продукт бесплатный, единственный «продукт» — подписка на канал. Стоит ли усиливать связку «прошёл тему → предложение посмотреть видео на канале / подписаться», или это отвлекает от учёбы?
