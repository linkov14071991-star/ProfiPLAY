## 1. Что это за продукт

**Адаптивный тренажёр подготовки к ОГЭ/ЕГЭ по информатике через Python.** Работает как Telegram Mini App внутри «Профик Арены».

Ключевая идея: ученик проходит структурированный курс от простого к сложному (как в Duolingo), с теорией, видео автора, тренировочными вопросами, персональными рекомендациями и ориентацией на конкретные номера задач экзамена. Прогресс и баллы едины с остальной Ареной.

## 2. Механика и экраны

**Путь ученика:**

1. **Онбординг (один раз при первом входе):** Профик здоровается, спрашивает цель (ОГЭ / ЕГЭ / просто выучить) и опыт. Если ученик не новичок — placement-тест из 6 вопросов возрастающей сложности. По результату рекомендуется стартовая тема (уроки ниже помечаются пройденными). Варианты ответов перемешиваются.
2. **Дерево тем:** список всех тем от «print» до задач ЕГЭ. Уроки открываются по порядку, за пройденные — галочка и корона за точность (⭐ ≥ 80%, 👑 = 100%). Полностью пройденные темы сворачиваются в заголовок, чтобы не листать.
3. **Верхняя панель дерева:** «План на сегодня», «Индекс готовности», баннер Профика, «Тест недели», «Ежедневное повторение», «Мини-проекты», «Видео-марафон».
4. **Теория (по желанию):** перед уроками предлагается изучить теорию темы — краткое объяснение с примерами, советами «частая ошибка» и видео. Не обязательна.
5. **Урок:** 6-12 заданий, 5 сердечек. Ошибка → минус сердце, объяснение, вопрос уходит в конец очереди. После ошибки в «что выведет код» доступна пошаговая трассировка. Кончились сердца → урок заново.
6. **Результат:** XP, точность, серия, рейтинг (за первое прохождение).

**Механики удержания:** сердечки, streak (дни подряд), ежедневное повторение из пройденного, тест недели (ротация тем, сброс в понедельник), короны за точность.

## 4. Система баллов

- **XP** — опыт для уровня аккаунта и ачивок. Начисляется всегда (за любой урок, повтор, ежедневку).
- **Рейтинг** — общий рейтинг Арены (лиги, лидерборд). Начисляется ТОЛЬКО за первое прохождение урока/проекта (2-15 баллов от сложности и точности). Повторы, ежедневки, тесты недели — только XP. Сервер хранит зачтённые уроки — накрутка повторами невозможна.
- **Индекс готовности (0-100):** точность 40% + стабильность 25% + скорость 20% + сложные задачи (боссы) 15%. Нерешённые задачи-боссы держат готовность ниже 85.

## 5. Персонализация

- **Память Профика:** отслеживает точность по каждой теме, находит слабую (<75%), предлагает целевое повторение. Реплики адаптируются: слабая тема / возврат после перерыва / похвала сильной темы / streak.
- **«План на сегодня»:** авто-план из статистики — повторить слабое, исправить 3 ошибки, решить задачу ЕГЭ, посмотреть видео.
- **Телеметрия:** собирает старт/финиш урока, правильность, первую попытку, время ответа, использование трассировки/видео/теории.

## 6. Техническая архитектура

- **Frontend:** ванильный JS (ES-модули), без фреймворков. Telegram Mini App.
- **Хранение прогресса:** двойное — Telegram CloudStorage + localStorage, выбор свежей версии по метке времени (защита от лимита 4096 байт).
- **Backend:** FastAPI на Railway. Эндпоинты начисления XP/рейтинга и приёма телеметрии.
- **Контроль качества:** весь выводимый контент прогоняется через реальный Python-интерпретатор. Автосканер проверяет, что каждый концепт из вопросов есть в теории.
- **Трассировка:** мини-интерпретатор Python на JS проигрывает код по шагам; показывается только если вывод совпал с проверенным ответом.

## 9. ВСЯ ТЕОРИЯ по темам

### 🖥️ Первые шаги (ОГЭ)

*Любая программа общается с человеком через вывод на экран. За это отвечает команда print — первое, что ты научишься делать. Всё, что стоит в скобках, окажется на экране.*

**Команда print**

print печатает то, что стоит в скобках. Текст обязательно берётся в кавычки — одинарные или двойные, разницы нет.

```python
print("Привет, мир!")
```
```
→ Привет, мир!
```
> 💡 Кавычки на экран не попадают — они лишь говорят Python «это текст».


**Числа без кавычек**

Если в скобках число или пример без кавычек — Python сначала посчитает, а потом выведет результат. С кавычками же он выведет всё буквально.

```python
print(2 + 3)
print("2 + 3")
```
```
→ 5
2 + 3
```
> 💡 Сравни: print(2+3) даёт 5, а print("2+3") даёт «2+3». Кавычки решают всё.


**Несколько значений**

Через запятую можно вывести несколько значений в одну строку — между ними Python сам поставит пробел.

```python
print("Ответ:", 42)
```
```
→ Ответ: 42
```
> 💡 Запятая = пробел между значениями. Если пробел не нужен — склеивай строки плюсом.


**Каждый print — с новой строки**

По умолчанию каждый print переносит курсор на новую строку. Поэтому два print печатают на двух строках.

```python
print("раз")
print("два")
```
```
→ раз
два
```
> 💡 Чтобы печатать в одну строку, добавь аргумент end=" ": print("раз", end=" ").


**Комментарии**

Всё, что идёт после символа #, Python не выполняет — это заметка для человека. Комментарии помогают не забыть, что делает код.

```python
print("ок")  # это комментарий, его Python игнорирует
```

🎬 Видео: Установка и первая программа

### 📦 Переменные (ОГЭ)

*Переменная — это коробка с именем, в которой хранится значение. Ты кладёшь туда число или текст, а потом обращаешься по имени. Значение в коробке можно менять сколько угодно раз.*

**Создание переменной**

Знак = кладёт значение справа в переменную слева. Читается «положить в x пятёрку», а не «x равно 5».

```python
x = 5
print(x)
```
```
→ 5
```
> 💡 Направление важно: слева переменная, справа значение. Наоборот (5 = x) — ошибка.


**Значение можно менять**

Каждое новое присваивание перезаписывает старое. В коробке всегда только последнее значение.

```python
x = 5
x = 10
print(x)
```
```
→ 10
```
> 💡 Частый приём: x = x + 1 — берём старое значение, увеличиваем, кладём обратно.


**Числа и строки**

В кавычках — строка (текст, тип str). Без кавычек цифры — число (тип int). Это разные типы, и вести себя они будут по-разному.

```python
a = 7        # число int
b = "7"      # строка str
print(a + a)
print(b + b)
```
```
→ 14
77
```
> 💡 Число складывается (7+7=14), а строка склеивается ("7"+"7"="77"). Не перепутай!


**Как узнать тип — type()**

type(значение) показывает, какого оно типа: целое (int), строка (str), дробное (float).

```python
print(type(5))
print(type("5"))
```
```
→ <class 'int'>
<class 'str'>
```

**Имена переменных**

Имя состоит из букв, цифр и знака _, но не может начинаться с цифры и не может содержать пробелов. Регистр важен: x и X — разные переменные.

```python
my_var = 1   # можно
x2 = 2       # можно
```
> 💡 2x, my var, my-var — так нельзя. Имя лучше делать понятным: summa, а не s1.


🎬 Видео: Вывод, типы данных и переменные

### ⌨️ Ввод данных (ОГЭ)

*Чтобы программа реагировала на человека, ей нужно считать введённые данные. За это отвечает input. Главное правило, которое ломает половину новичков: input всегда возвращает строку.*

**Команда input**

input() ждёт, пока человек что-то напечатает и нажмёт Enter, и возвращает введённое как строку.

```python
name = input()
print("Привет,", name)
```

**Важно: input даёт строку**

Даже если ты ввёл цифры, для Python это текст. Поэтому "5" + "5" не 10, а склейка "55".

```python
x = input()   # ввели 5
print(x + x)
```
```
→ 55
```
> 💡 Это самая частая ошибка на входе. Если нужно считать, оборачивай в int().


**Превращаем в число**

int() превращает строку в целое число. Только после этого с введённым можно считать.

```python
x = int(input())  # ввели 5
print(x + x)
```
```
→ 10
```
> 💡 Запомни готовую конструкцию: x = int(input()) — считать целое число.


**Дробные числа**

Если число может быть с точкой (например 3.5), используй float(input()) вместо int.

```python
x = float(input())  # ввели 2.5
print(x * 2)
```
```
→ 5.0
```

### ➗ Арифметика (ОГЭ)

*Python умеет считать. Кроме обычных + - * есть важные для экзамена деление, остаток и степень.*

**Деление нацело //**

Отбрасывает дробную часть. 17 // 5 = 3.

```python
print(17 // 5)
```
```
→ 3
```

**Остаток от деления %**

Сколько осталось после деления нацело. 17 % 5 = 2, потому что 17 = 5·3 + 2. Остаток — важнейший инструмент на ЕГЭ.

```python
print(17 % 5)
```
```
→ 2
```
> 💡 n % 10 даёт последнюю цифру числа, n // 10 убирает её — так разбирают число на цифры.


**Чётность через остаток**

Число чётное, если делится на 2 без остатка, то есть x % 2 == 0. Результат сравнения — True или False.

```python
x = 10
print(x % 2 == 0)
```
```
→ True
```
> 💡 Так же проверяют делимость на любое число: кратно 3 — это x % 3 == 0.


**Степень ****

Возведение в степень. 2 ** 10 = 1024.

```python
print(2 ** 10)
```
```
→ 1024
```

**Обычное деление /**

Один слэш всегда даёт дробь: 7 / 2 = 3.5.

```python
print(7 / 2)
```
```
→ 3.5
```

🎬 Видео: Арифметика чисел; Вещественные числа и тип float; Арифметика строк

### 🔀 Условия (ОГЭ)

*Программа может выбирать путь в зависимости от условия. Это делает if.*

**if — если**

Если условие истинно — выполнится код с отступом.

```python
x = 7
if x > 5:
    print("много")
```
```
→ много
```

**else — иначе**

Что делать, если условие ложно.

```python
x = 3
if x > 5:
    print("много")
else:
    print("мало")
```
```
→ мало
```

**Сравнения**

Равно ==, не равно !=, больше >, меньше <, >=, <=. Внимание: == сравнивает, а один = присваивает.


**elif — иначе если**

Проверить ещё условие, если предыдущее не сработало.

```python
if x > 0:
    print("плюс")
elif x < 0:
    print("минус")
else:
    print("ноль")
```

**Отступы важны**

Тело if пишется с отступом (4 пробела). Без отступа Python не поймёт, что относится к условию.


🎬 Видео: Условный оператор, операции сравнения; Составные условия, логический тип

### 🔁 Цикл while (ОГЭ)

*Цикл while повторяет действия, пока условие остаётся истинным.*

**Пока верно — повторяй**

Тело while выполняется снова и снова, пока условие True.

```python
i = 1
while i <= 3:
    print(i)
    i = i + 1
```
```
→ 1
2
3
```

**Счётчик обязателен**

Внутри цикла обязательно нужно менять переменную из условия (например, i = i + 1). Если этого не сделать, условие всегда останется истинным и цикл никогда не закончится.

```python
i = 1
while i <= 3:
    print(i)
    i = i + 1
```
```
→ 1
2
3
```
> 💡 Забыл i = i + 1 — получил вечный цикл. Это ошибка №1 в while.


**Накопление суммы**

Очень частый приём: заводим накопитель s = 0 до цикла и в каждом шаге что-то прибавляем. После цикла в s лежит итог.

```python
s = 0
i = 1
while i <= 4:
    s = s + i
    i = i + 1
print(s)
```
```
→ 10
```
> 💡 Тот же приём работает и с for. Накопитель заводят ДО цикла, печатают ПОСЛЕ.


**Разбор числа на цифры**

Классика ЕГЭ: n % 10 берёт последнюю цифру, n // 10 отрезает её. Повторяем, пока число не станет 0.

```python
n = 253
s = 0
while n > 0:
    s = s + n % 10
    n = n // 10
print(s)
```
```
→ 10
```
> 💡 Этот шаблон (сумма/произведение/количество цифр) встречается на экзамене постоянно.


🎬 Видео: Цикл WHILE

### 🔂 Цикл for и range (ОГЭ)

*Когда известно, сколько раз повторить, удобнее for с range.*

**for и range**

range(n) даёт числа от 0 до n-1. Счёт начинается с нуля, а правая граница НЕ входит. Цикл for проходит по этим числам по очереди.

```python
for i in range(3):
    print(i)
```
```
→ 0
1
2
```
> 💡 range(3) — это три числа: 0, 1, 2. Само число 3 не входит. Это ловушка №1 на ЕГЭ.


**range с началом**

range(1, 4) — от 1 до 3 включительно. Первое число входит, последнее (4) — нет.

```python
for i in range(1, 4):
    print(i)
```
```
→ 1
2
3
```
> 💡 Сколько чисел в range(a, b)? Ровно b - a штук.


**range с шагом**

Третий аргумент — шаг, размер прыжка. range(0, 10, 2) идёт через одно: 0, 2, 4, 6, 8.

```python
for i in range(0, 10, 2):
    print(i)
```
```
→ 0
2
4
6
8
```

**Шаг назад**

Отрицательный шаг заставляет цикл идти вниз. range(5, 0, -1) даёт 5, 4, 3, 2, 1.

```python
for i in range(5, 0, -1):
    print(i)
```
```
→ 5
4
```

### 🔀 itertools (задачи 8, 15) (ЕГЭ)

### 🔁 Рекурсия и кэш (задача 16) (ЕГЭ)

*Задача 16 — про рекурсивные функции. Когда рекурсия глубокая (большие n), она тормозит или падает. Спасают два приёма: кэш @lru_cache или замена рекурсии на заполнение массива.*

**Что такое рекурсия**

Функция вызывает саму себя. Обязателен базовый случай — условие, при котором функция перестаёт вызывать себя и возвращает готовый ответ. Без него — бесконечный вызов.

```python
def F(n):
    if n <= 2:
        return n
    return F(n - 1) + F(n - 2)
print(F(6))
```
```
→ 13
```

**Кэш @lru_cache**

@lru_cache запоминает уже посчитанные значения, чтобы не считать их заново. Ставится строго НАД def, без пустой строки. Число в скобках — размер кэша (обычно 10000 или больше).

```python
from functools import lru_cache
@lru_cache(10000)
def G(n):
    if n <= 20:
        return n + 2
    return G(n - 3) + 1
```
> 💡 Без кэша функция вроде чисел Фибоначчи считает одно и то же тысячи раз и зависает.


**Надёжнее — массив без рекурсии**

Самый безопасный способ для больших n: завести массив F и заполнить его циклом от начала к концу. Никакой глубокой рекурсии — ничего не упадёт.

```python
F = [0] * 100
for n in range(100):
    if n < 10:
        F[n] = n + 2
    else:
        F[n] = F[n - 3] + 1
print(F[50])
```
```
→ 24
```

**НЕ поднимай лимит рекурсии**

Команда setrecursionlimit теоретически разрешает больше вызовов, но на экзамене работает нестабильно — Python может упасть прямо на проверке, и баллы потеряны. Всегда выбирай @lru_cache или массив.


**Шпаргалка**

@lru_cache(N) над функцией — кэш до N значений; @lru_cache(maxsize=None) — без ограничения. Массив F[n], заполненный циклом — самый надёжный вариант для задачи 16.


### 🔎 Регулярки re (задача 24) (ЕГЭ)

*Регулярные выражения (модуль re) — мощный способ искать шаблоны в длинной строке. Главный инструмент задачи 24. Ты описываешь «маску» из спецсимволов, а Python находит все куски строки, которые под неё подходят.*

**finditer — главная функция**

finditer проходит по ВСЕМ совпадениям в строке. У каждого совпадения m есть m.group() — сам текст, m.start() и m.end() — индексы начала и конца. Именно finditer чаще всего нужен в задаче 24.

```python

s = 'A12B345C6'
for m in finditer(r'[0-9]+', s):
    print(m.group())
```
```
→ 12
345
6
```
> 💡 m.start() и m.end() дают позицию совпадения — часто нужны, чтобы проверить, что идёт рядом.


**findall — просто список**

Если позиции не нужны, findall сразу возвращает список всех совпадений — короче, чем finditer.

```python
from re import findall
print(findall(r'[0-9]+', 'A12B345C6'))
```
```
→ ['12', '345', '6']
```

**search и fullmatch**

search — первое совпадение (или None). fullmatch — подходит ли ВСЯ строка целиком под шаблон.

```python
from re import search
print(search(r'[0-9]+', 'ab12cd').group())
```
```
→ 12
```

**Символьные классы**

Задают, какой символ разрешён в одной позиции: [ABC] — один из A,B,C; [A-Z] — любая буква диапазона; [0-9] — цифра; [^A] — любой символ, КРОМЕ A; точка . — вообще любой символ.


**Квантификаторы (сколько раз)**

Ставятся после символа/класса: * — 0 и больше повторов; + — 1 и больше; ? — 0 или 1; {n} — ровно n раз; {n,m} — от n до m раз.

```python
from re import findall
print(findall(r'[0-9]{2,3}', 'a1b22c333'))
```
```
→ ['22', '333']
```

**Жадность и лень (ключ задачи 24!)**

По умолчанию квантификаторы жадные — захватывают КАК МОЖНО БОЛЬШЕ. Добавишь ? после квантификатора — станут ленивыми и возьмут МИНИМУМ. Из-за жадности можно случайно склеить несколько чисел в одно.

```python
from re import findall
print(findall(r'<.+>', '<a><b>'))
print(findall(r'<.+?>', '<a><b>'))
```
```
→ ['<a><b>']
['<a>', '<b>']
```
> 💡 Жадные: * + ? {n,m}. Ленивые: *? +? ?? {n,m}?. При поиске чисел между разделителями почти всегда нужна лень.


**Группировка и альтернатива**

(AB)+ — пара AB повторяется; AB|CD — либо AB, либо CD. Чтобы искать сам спецсимвол, его экранируют: \* \+ \. \( \).


**Префикс r обязателен**

Всегда пиши r"шаблон" (raw-строка). Тогда обратный слэш \ Python не трогает, и он достаётся регулярке как есть.

**Поиск делителя (до корня!)**

Делители идут парами: если d делит n, то и n//d. Достаточно дойти до √n — в разы быстрее.

```python
def div(n):
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            if d % 10 == 7:
                return d
            if (n // d) % 10 == 7:
                return n // d
    return 0
print(div(119))
```
```
→ 7
```
